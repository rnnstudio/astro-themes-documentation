# astro-themes-documentation

Documentation site for Astro templates. Each template's docs live in their own folder (e.g. `paytime-astro-doc/`, `sasdesk-astro-doc/`, `seoguru-astro-doc/`), built from the shared `doc-skeleton/` layout. `index.html` links to each template's docs.

## Git

When committing and pushing changes in this repo, use:

```
https://github.com/rnnstudio/astro-themes-documentation
```

This is already configured as the `origin` remote.
